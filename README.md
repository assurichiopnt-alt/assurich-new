## จุดแก้ไขใน index.html
| ต้องการแก้ | ค้นหาคำนี้ในไฟล์ |
|---|---|
| รูปบนการ์ด / รูปประกอบ | `const ART` (รวมภาพจริงและภาพวาด SVG) |
| ชื่อการ์ด / สี / คำบรรยาย | `const SLIDES` |
| ลิงก์แบรนด์ | `ROBOT_COBOT`, `ROBOT_LIFT`, `ERW` และ `insitools.com` |

| ข้อความแถบตัววิ่ง | `const words` |
| เบอร์โทร / อีเมล Support | `support-panel` |
| ขนาดการ์ด | `.slide{` → `width:clamp(...)` |
